# Meu Guia de Git

Anotações pessoais feitas durante o aprendizado de Git, reunindo os principais comandos e fluxos de trabalho para consulta rápida no dia a dia.

## Conteúdo
- Comandos básicos (init, add, commit, status, log)
- Trabalho com branches (criar, alternar, mesclar)
- Sincronização com repositório remoto (push, pull, clone)
- Resolução de conflitos simples

Criado como material de estudo próprio, para reforçar o aprendizado e servir de referência futura.
